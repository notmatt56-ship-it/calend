Подключите Google Календарь

Для синхронизации нужен Client ID от Google. Настройка делается один раз:

  1. Откройте console.cloud.google.com, создайте проект и включите Google Calendar API.
  2. В разделе «OAuth consent screen» выберите External, а в Test users добавьте свою почту.
  3. В «Credentials» создайте OAuth client ID типа Web application. В «Authorized JavaScript origins» укажите адрес сайта, например https://username.github.io.
  4. Скопируйте Client ID и вставьте его в начало скрипта в index.html: const GOOGLE_CLIENT_ID = '...'.

Пока Client ID не указан, можно выгрузить все задачи со сроками файлом .ics и импортировать его в Google Календарь вручную (Настройки → Импорт и экспорт).
